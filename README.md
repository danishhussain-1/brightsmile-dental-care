# 🦷 BrightSmile Dental Care – Modern Dental Clinic Website

A modern, responsive, and production-ready dental clinic website built with **Django**. This project provides a complete online platform for dental clinics, allowing patients to book appointments, explore dental services, read informative blogs, view doctor profiles, and contact the clinic through an elegant and user-friendly interface.

🌐 **Live Demo:**https://brightsmileclinic.pythonanywhere.com/
---

# 📌 Project Overview

BrightSmile Dental Care is a full-stack dental clinic web application developed to enhance the digital presence of modern dental practices. It offers an intuitive experience for patients while providing an efficient management system for clinic administrators.

The project focuses on clean UI, responsive design, performance, accessibility, and user-friendly navigation across all devices.

# 🚀 Installation

```bash
git clone https://github.com/danishhussain-1/brightsmile-dental-care.git

cd brightsmile-dental-care

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py createsuperuser

python manage.py runserver
```
